# 2D Metroidvania Platformer Prototype

This repository contains the core mechanics prototype for "Dark Knight," a 2D action-adventure game that won **1st Prize in a Technical Hub Gaming Contest**

---

### Project Overview

This project was a technical study focused on recreating the signature mechanics and atmosphere of the game *Hollow Knight*. The goal was to build a robust character controller and game systems from the ground up in Unity
The final, fully integrated version of the game was built using the original assets from *Hollow Knight* to provide an authentic foundation for the technical work. Unfortunately, that final Unity project was lost due to data corruption.

This repository contains my own work: the clean, functional prototype that served as the technical foundation for the final game.

### Key Features I Implemented

As the sole developer, I was responsible for all programming and systems design.

#### 1. Advanced Player Mechanics (C#)
* **Precise Platformer Controller:** A complete character controller featuring **Variable Jump** , **Wall Jump** , and **Coyote Time**  for a responsive and fair platforming experience.
* **Dynamic Combat System:** A fast-paced melee system allowing attacks in four directions , with satisfying enemy **Recoil**.
* **Interactive Environments:** Systems for dynamic elements and secret **hidden room entrances**.

#### 2. Technical Artistry
* **Atmosphere & Immersion:** Dynamic **2D lighting**  and a custom-coded, multi-layered **parallax effect** to create a rich sense of depth.
* **Custom Visual Effects:** Designed and implemented unique **particle effects** for key gameplay actions like attacking and taking damage.
